## Conventions used in this part

- Inside backticks `\n` is one LF byte (0x0A). A real TAB is written "U+0009"; the two-character word backslash-`t` is always called out in words. No text produced by this surface itself contains CR.
- `→` is U+2192 RIGHTWARDS ARROW, UTF-8 bytes `E2 86 92`. It is never the ASCII pair `->`.
- "stderr, exit 2" / "stderr, exit 1" always also means: stdout is empty (0 bytes) unless the clause says otherwise.
- Provenance abbreviations: `args.rs` = `legacy/Toon/src/cli/args.rs`; `mod.rs` = `legacy/Toon/src/cli/mod.rs`; `main.rs`, `error.rs`, `options.rs`, `conversion.rs` likewise under `legacy/Toon/src/`; `clap:` = `clap_builder-4.6.6/src/`; `strsim:` = `strsim-0.11.1/src/`; `anstream:` = `anstream-1.0.0/src/`. `[run]` marks a statement verified by an oracle run made for this part (listed in the Extractor report); `[inference]` marks a statement read from source and not separately observable.
- `<prog>`: the program name printed in `Usage:` lines (S1.2). All goldens have `toon`; templates below write `toon`.
- "C" and "P" are the committed list and the pending item of S1.13. They are descriptive devices for the observable precedence and `Usage:` rules, not a data-structure prescription.

```text
Usage: toon [OPTIONS] [INPUT]

Arguments:
  [INPUT]  Input file path (omit or use "-" to read from stdin)

Options:
  -o, --output <FILE>                Output file path (stdout if omitted)
  -e, --encode                       Encode JSON to TOON (auto-detected by default)
  -d, --decode                       Decode TOON to JSON (auto-detected by default)
      --delimiter <DELIMITER>        Delimiter for arrays: comma (,), tab (\t), or pipe (|) [default: ,]
      --indent <INDENT>              Indentation size (spaces) [default: 2]
      --no-strict                    Disable strict mode for decoding (allows lenient parsing)
      --key-folding <KEY_FOLDING>    Key folding mode: off or safe [default: off] [possible values: off, safe]
      --flatten-depth <N>            Maximum folded segment count when key folding is enabled
      --expand-paths <EXPAND_PATHS>  Path expansion mode: off or safe (decode only) [default: off] [possible values: off, safe]
      --stats                        Show token statistics (encode only)
  -h, --help                         Print help
  -V, --version                      Print version

EXAMPLES:
    toon input.json                  # Encode JSON to TOON (stdout)
    toon input.toon                  # Decode TOON to JSON (stdout)
    toon input.json -o output.toon   # Encode to file
    cat data.json | toon --encode    # Encode from stdin
    cat data.toon | toon --decode    # Decode from stdin
    toon input.json --stats          # Show token statistics
```
